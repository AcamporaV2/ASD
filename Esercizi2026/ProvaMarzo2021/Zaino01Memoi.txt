Scrivere un algoritmo in pseudocodice, che risolva il problema dello zaino 01, utilizzando la tecnica della memoization


Sia M[0...n,0...W] una tabella n+1 x W+1


ZainoMemoi(v,w,i,j,M)

    if M[i,j] != NIL 
        return M[i,j] 

    if i == 0 or j == 0 
        M[i,j] = 0 
        return 0 
    //peso maggiore di capacità j 
    if w[i] > j 

        M[i,j] = ZainoMemoi(v,w,i-1,j,M)
    else 

        Incluso = v[i] + ZainoMemoi(v,w, i-1, j- W[i], M)
        Escluso = ZainoMemo(v,w,i-1,j,M)

        M[i,j] = max(Incluso, Escluso)
    
    return M[i,j]
