Una pizzeria durante una partita di calcio ha contemporaneamente richieste di pizze da più clienti.
Il pizzaiolo deve infornare quindi p pizze, ciascuna con tempo T[p] di cottura. 
Bisogna schedulare le pizze dando in input al forno le pizze 𝑝1...𝑝𝑛e 
i corrispondenti tempi 𝑇[𝑝1]...𝑇[𝑝𝑛], in modo da minimizzare il tempo medio di attesa per il cliente.




SJF(T[1...N])

Coda_pizze <- Coda vuota
for i = 1 to N
    Insert(Coda_pizze, t[i])

tempo_completamento = 0
tempo_attesa_totale = 0

while Coda_pizze non è vuota
    Pizza = EXTRACT-MIN(Coda_pizze)

    tempo_completamento = tempo_completamento + tempo_pizza

    tempo_attesa_totale = tempo_attesa_totale + tempo_completamento

    
Media = tempo_attesa_totale / N


return Media
