

Dato una coda di min priorità, implementata mediante un heap, scrivere un algoritmo che restituisca, 
come output, il numero degli scambi necessari ad eseguire il metodo EXTRACT_MIN.



EXTRACT-MIN(A)

if A.heapsize <1 
    error "heapsize"

A[1] = A[A.heapsize]
A.heapsize = A.heapsize -1

return HEAPIFY(A, 1)




HEAPIFY(A, i)

scambi = 0

l = left(i)
r = right(i)

if l <= A.heapsize and A[l] < A[i]
    minimo = l 
else minimo = i

if r <=A.heapsize and A[r] < A[minimo]
    minimo = r


if minimo != i 
    swap A[i] <-> A[minimo]
    scambi = 1 + (HEAPIFY(A, minimo))

return scambi
