EDIT-DISTANCE(X, Y)
// Input: X stringa di lunghezza m, Y stringa di lunghezza n
// Output: distanza di editing tra X e Y

1.  m = length[X]
2.  n = length[Y]
3.  sia DP[0..m, 0..n] una nuova tabella
4.  
5.  // Inizializzazione casi base
6.  for i = 0 to m
7.      DP[i, 0] = i
8.  for j = 0 to n
9.      DP[0, j] = j
10. 
11. // Riempimento della tabella con programmazione dinamica
12. for i = 1 to m
13.     for j = 1 to n
14.         if X[i] == Y[j]
15.             cost = 0
16.         else
17.             cost = 1
18.         
19.         DP[i, j] = min(DP[i-1, j] + 1,        // cancellazione
20.                        DP[i, j-1] + 1,        // inserimento
21.                        DP[i-1, j-1] + cost)   // sostituzione
22. 
23. return DP[m, n]
