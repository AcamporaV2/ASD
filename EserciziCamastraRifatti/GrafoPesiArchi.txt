Dato un grafo orientato G=(V,E) con funzione peso w e sorgente s, scrivere un algoritmo che restituisca TRUE se in G è presente almeno 
un ciclo di peso negativo e FALSE altrimenti.
 Nel caso in cui venga individuato un ciclo di peso negativo restituire la somma dei pesi degli archi coinvolti ne ciclo


BELLMANFORD(G,w,s)

for each u in V[G] -{s}
    d[u] = infinito
    padre[u] = NIL 

d[s] = 0 


for i-1 to |V[G]|- 1
    for each (u,v) in E[G]
        if d[v] > d[u] + w(u,v)
            d[v] = d[u] + w(u,v)
            padre[v] = u 


for each (u,v) in E[G]
    if d[v] > d[u] + w(u,v)

        //Ciclo negativo 
        somma = 0 
        nodo = u 

        for j = 1 to |V[G]|
            nodo = padre[nodo]
        
        inizio_ciclo = nodo 

        repeat 
            next = padre[nodo]
            somma = somma + w(next, nodo)
            nodo = next 
        until nodo == inizio ciclo 

        retrun(TRUE, somma)

return(false,0)
