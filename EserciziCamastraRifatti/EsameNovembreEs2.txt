Dato un grafo orientato $G = (V, E)$ si scriva in pseudocodice un algoritmo che restituisca 
il numero dei cicli, escludendo i cappi, presenti nel grafo. (7 punti)

DFS(g)

for each u in V[G]
    color[u] = white 
    padre[u] = NIL 

time = 0 
cicli = 0

for each u in V[G]
    if color == white 
        DFS-VISIT(u,cicli)

return cicli



DFS-VISIT(u,cicli)

color[u] = gray 
time = time +1 
d[u] = time

for each v in Adj[u]
    if color[v] == WHITE 
        
        padre[v] = u 
        DFS-VISIT(u,cicli)
    
    else if color[v] == GRAY 
        if v!=u 
            cicli = cicli + 1

color[u] = black 
time = time +1 
f[u] = time
