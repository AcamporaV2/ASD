se esiste un arco all’indietro, altrimenti FALSE.
Determinare il caso peggiore ed il caso migliore

    -ultimo nodo oppure non presente
Caso migliore:
    -presto nell'esplorazione

    color[u] = white 
    padre[u] = NIL

    if color[u] == white

            return true

return false
