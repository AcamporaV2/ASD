Dato un grafo orientato G = (V,E) e pesato con funzione peso w: E -> R ed un nodo sorgente s € V, scrivere un algoritmo, 
in pseudocodice, che restituisca la profondità massima dei cammini minimi



//BELLMAN-FORD PERCHE' USIAMO PESI REALI 


for each u in V[G] - {s}

    dist[u] = infinito
    padre[u] = NIL 
    profondita[u] = 0

dist[s] = 0 
profondita[s] = 0 


for i = 0 to V[G] - 1

    for each (u,v) in E[G] 
        if d[v] > dist[u] + w(u,v)
            d[v] = dist[u] + w(u,v)
            padre[v] = u 
            profondita[v] = profondita[u] + 1


max_profondita = 0

for each u in V[G] 
    if dist[u] != infinto 
        if profondita[u] > max_profondita
            max_profondita = profondita[u]

return profondita
