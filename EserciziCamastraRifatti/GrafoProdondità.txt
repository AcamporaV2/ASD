Dato un grafo G(V,E) orientato e pesato (con pesi w: E -> R) e un nodo sorgente s ∈ V, 
si vuole trovare la profondità massima (numero di archi) tra tutti i cammini minimi che partono da s.




BELLMAN-FORD per le distanze 


BELLMAN_FORD_MAX_PROFONDITA(G, w, s)

    // 1. Inizializzazione
    for each u in V[G]
        d[u] = +∞
        h[u] = 0
    d[s] = 0

    // 2. Rilassamento degli archi
    for i = 1 to |V[G]| - 1
        for each (u, v) in E[G]
            if d[u] != +∞
                
                // Caso 1: Scoperto un cammino con costo strettamente inferiore
                if d[v] > d[u] + w(u, v)
                    d[v] = d[u] + w(u, v)
                    h[v] = h[u] + 1
                
                // Caso 2: Scoperto un cammino minimo alternativo
                else if d[v] == d[u] + w(u, v)
                    // Aggiorniamo solo se il nuovo cammino ha più archi
                    if h[v] < h[u] + 1
                        h[v] = h[u] + 1

    // 3. Verifica cicli di peso negativo (standard)
    for each (u, v) in E[G]
        if d[u] != +∞ and d[v] > d[u] + w(u, v)
            return "Errore: Ciclo di peso negativo"

    // 4. Estrazione della massima profondità tra tutti i cammini minimi
    max_profondita = 0
    for each u in V[G]
        if d[u] != +∞ and h[u] > max_profondita
            max_profondita = h[u]

    return max_profondita
