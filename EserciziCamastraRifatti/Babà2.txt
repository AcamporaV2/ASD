
Sei una madre e vuoi comprare per festeggiare dei babà a tuo figlio. 
Hai solo E euro e la pasticceria sfortunatamente ha solo N torte di babà e non i babà singoli. 
Ogni torta di babà però ha B[t] babà interni (cioè la torta di babà è come se fosse un contenitore).
Ogni torta di babà da c(t) come costo. Quanti babà al massimo puoi ricavare con E euro?

GREEDY-BABA-FRAZIONARIO(c, B, N, E)
 per i = 1 a N
     // Calcoliamo la densità: babà per ogni euro
      ratio[i] = B[i] / c[i]
  
    ordina le torte da 1 a N tale che ratio[1] ≥ ratio[2] ≥ ... ≥ ratio[N]
    totale_baba = 0       // Il bottino totale
    soldi_rimasti = E     // Il portafoglio della mamma
    i = 1 

while soldi_rimasti > 0 and i <= N
    if c[i] <= soldi_rimasti
        // Caso 1: Compro tutta la torta
                soldi_rimasti = soldi_rimasti - c[i]
        totale_baba = totale_baba + B[i]
    else
       // Caso 2: Compro solo una frazione
       frazione = soldi_rimasti / c[i]
        totale_baba = totale_baba + (B[i] * frazione)
        soldi_rimasti = 0   // Questo farà terminare il while al prossimo check

   i = i + 1    // Passo alla prossima torta

return totale_baba
